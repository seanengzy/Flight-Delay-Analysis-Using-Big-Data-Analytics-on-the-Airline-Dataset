# Big Data Airline Analysis

This repository contains four implementations used to analyse the airline dataset and compare their execution performance.

## Files

- `Pandas.ipynb`  
  Performs the data analysis using Pandas.

- `PySpark.ipynb`  
  Performs the data analysis using PySpark.

- `SparkSQL.ipynb`  
  Performs the data analysis using Spark SQL.

- `duckdb.ipynb`  
  Performs the data analysis using DuckDB SQL.

- `Time_Execution_Graphs.ipynb`  
  Summarises and compares the execution time of Pandas, PySpark, Spark SQL, and DuckDB using graphs.

## Purpose

The purpose of these notebooks is to compare different big data processing approaches based on their analysis results and execution time.
